# IP Adresleri

IP (Internet Protocol) adresi, ağa bağlı her cihaza verilen benzersiz bir kimlik numarasıdır. Cihazlar ağ üzerinde birbirlerini IP adresleri sayesinde bulur ve veri alışverişi yapar.

Bir IP adresi sayesinde gönderilen verinin hangi cihazdan geldiği ve hangi cihaza gideceği belirlenir.

## IP Adresi Ne İşe Yarar?

* Cihazları ağ üzerinde tanımlar.
* Cihazlar arasında iletişim kurulmasını sağlar.
* Verilerin doğru hedefe ulaşmasını sağlar.

## IP Adresi Türleri

### IPv4

IPv4, günümüzde en yaygın kullanılan IP adresi sürümüdür. 32 bit uzunluğundadır ve dört sayı grubundan oluşur.

Örnek:

`192.168.1.10`

---

### IPv6

IPv6, IPv4 adreslerinin yetersiz kalması nedeniyle geliştirilen yeni nesil IP adresidir. 128 bit uzunluğundadır ve çok daha fazla adres sunar.

Örnek:

`2001:0db8:85a3:0000:0000:8a2e:0370:7334`

## Public IP ve Private IP

### Public IP

İnternet üzerinde kullanılan ve dünya genelinde benzersiz olan IP adresidir. İnternet servis sağlayıcısı (ISP) tarafından atanır.

Örnek:

Bir web sitesine erişirken kullanılan IP adresi.

### Private IP

Yerel ağlarda kullanılan IP adresidir. İnternet üzerinde doğrudan kullanılmaz.

Yaygın Private IP aralıkları:

* `10.0.0.0 - 10.255.255.255`
* `172.16.0.0 - 172.31.255.255`
* `192.168.0.0 - 192.168.255.255`

Örnek:

Evdeki bilgisayarınızın modemden aldığı `192.168.1.5` adresi.

## Statik ve Dinamik IP

* **Statik IP:** Değişmeyen, sabit IP adresidir.
* **Dinamik IP:** Belirli aralıklarla değişebilen IP adresidir ve genellikle DHCP tarafından otomatik atanır.

Kısaca:

**IP adresi, ağ üzerindeki cihazların birbirini tanımasını ve iletişim kurmasını sağlayan benzersiz adresidir.**
